Web Components demo

All 100 standalone elements from @dynamia-tools/tailadmin-vue-wc, registered via a single barrel import. Components with array/object/function-typed required props (tables, pickers with items, etc.) get their sample data assigned as DOM properties in main.ts — see the "Known limitations" section of the package README for why that can't be done via plain HTML attributes.
